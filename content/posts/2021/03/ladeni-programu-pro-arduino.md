<p><span>&nbsp; &nbsp; Zkuste to jinak.&nbsp;</span>Jak ověřit, že program funguje správně, že se v něm neděje nic neplánovaného? Ladit. Běžně se v Arduino světě používá ladění „sériový monitor.“ Takže si v programu ručně vypisuju, co se děje a co chci zkoumat. Ale co když chci opravdu debugovat, pohodlně krokovat program a mít pod kontrolou každou iteraci.</p><p><span>&nbsp; &nbsp; Debugger pro Arduino existuje, je dostupný a použitelný.</span><br /></p><h3 style="text-align: left;">Arduino UNO R3 (8bit)</h3><p><b><i>Xplained Mini (levná hardwarová cesta) pouze pro Arduino UNO/NANO</i></b></p><p></p><div class="separator" style="clear: both; font-weight: bold; text-align: center;"><a href="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgqZlGjoVFSwuckaxrRt-pRC-UyrsXNa-y6ZBJ5_rLXOOuPpDXUQ-Unm92XG9vuMknqcEVpiItnEBBARlKuvqQ90nPDZizX2alYloFDaGcfhGwqwAO50gaVx73FRlYSVOXK0Oi259TxNwXPEzKQijIWjdd03Cd_TPZVulrW2NCiuEfEZ6V8sXAy3CUNb-Fy/s853/xplained.JPG" imageanchor="1" style="margin-left: 1em; margin-right: 1em;"><img border="0" data-original-height="853" data-original-width="688" height="320" src="https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgqZlGjoVFSwuckaxrRt-pRC-UyrsXNa-y6ZBJ5_rLXOOuPpDXUQ-Unm92XG9vuMknqcEVpiItnEBBARlKuvqQ90nPDZizX2alYloFDaGcfhGwqwAO50gaVx73FRlYSVOXK0Oi259TxNwXPEzKQijIWjdd03Cd_TPZVulrW2NCiuEfEZ6V8sXAy3CUNb-Fy/s320/xplained.JPG" width="258" /></a></div><p style="text-align: right;"><span style="font-family: inherit;">dostupné na [<a href="https://mou.sr/3OK21QB" target="_blank">Mouser</a>]</span></p><p style="text-align: left;"><span style="font-family: inherit;">&nbsp; &nbsp; Velmi povedené řešení je deska přímo od výrobce procesoru s názvem v ATmega328P Xplained Mini [</span><a href="https://www.microchip.com/DevelopmentTools/ProductDetails/PartNO/ATMEGA328P-XMINI" style="font-family: inherit;" target="_blank">1</a><span style="font-family: inherit;">], která stojí srovnatelně jako nějaký čínský klon Arduina Uno. Xmini má stejné rozmístění pinů jako Arduino Uno, takže se dá připojit jakýkoli dostupný shield a odladit program pomocí debugWire.&nbsp;</span></p><p style="text-align: left;"><span>&nbsp;&nbsp; &nbsp;</span>K samotnému debugování potřebujeme Microchip Studio[<a href="https://www.microchip.com/en-us/development-tools-tools-and-software/microchip-studio-for-avr-and-sam-devices" target="_blank">2</a>] (dostupné zdarma), které umožňuje vytvořit nový projekt z našeho Arduino sketch. Jednoduché, elegantní, funkční. I pro někoho, kdo doposud používal pouze Arduino IDE je to použitelná cesta. Knihovny, které ve sketchi používám, si musím postupně naimportovat ručně (v seznamu knihoven je na pravém tlačíku myši volba Importovat Arduino knihovnu). Funguje to.</p><p><span>&nbsp; &nbsp; Xmini má micro USB konektor, který by častým používáním trpěl, proto má smysl použít krabičku[<a href="https://www.thingiverse.com/thing:4784628" target="_blank">3</a>] s oporou pro konektor.</span></p><p><b><i>Visual Micro (softwarové řešení) pro všechna Arduina</i></b></p><p>&nbsp; &nbsp; Softwarové ladění, které bude fungovat s každým typem Arduina je Visual Micro[<a href="https://www.visualmicro.com/" target="_blank">4</a>] je plugin pro Microsoft Visual Studio nebo pro Microchip Studio (Atmel Studio). Umí otevřít sketch pro Arduino, automaticky k vašemu kódu přidá ladící rozšíření a program se dá spustit, krokovat, zobrazit hodnoty proměnných. Celé to řešení má svá omezení, ale je použitelné. Pro ladění Arduino UNO/NANO můžete snadno narazit na paměťové limity, může být výhodnější použít výše zmíněné hardwarové řešení.</p><p><span>&nbsp; &nbsp; Visual Micro není zdarma, jedna&nbsp;</span>licence stojí kolem 12USD ročně.</p><p><b><i>Jde to i jinak?&nbsp;</i></b></p><p><span>&nbsp;&nbsp; &nbsp;</span>Ano jde, ale jsou to víc profi věci pro lidi, kteří programují mikrokontrolery, než pro bastlíře s arduinem.
